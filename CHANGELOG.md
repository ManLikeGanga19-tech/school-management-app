## [v0.9.0-beta] – 2025-11-03
### Added
- Student management module (register, edit, delete students)
- Basic fee tracking system
- Fee structure management
- Admin dashboard (overview of key stats)
- Teacher accounts with restricted access

### Fixed

### Known Issues
